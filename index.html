⚡ ElectroLab

AC & DC Virtual Circuit Construction Laboratory

How to use

  1. Select DC or AC mode.
  2. Drag components from the left toolbox.
  3. Place them inside the construction area.
  4. Click one terminal and then another terminal to create a connection.
  5. Click a component to change its properties.
  6. Press START SIMULATION.
  7. Observe voltage, current, power and waveform.

Keyboard

Delete → Remove selected component
Space → Start / pause simulation
R → Reset simulation
